Cómo funciona

Dos capas independientes, cada una responde una pregunta distinta.

API Karate confirma que el backend hace exactamente lo que dice el contrato — sin depender de cómo se vea la interfaz.
UI Playwright confirma que una persona real, usando el navegador, puede completar cada flujo sin errores.
Juntas Si algo se rompe en el backend o en la interfaz, una de las dos capas lo detecta antes de que llegue a producción.

Reportes generados localmente y publicados en esta página como una foto del último resultado. Actualización automática en cada cambio (CI/CD) está en el roadmap.
